# ALAQTAR Backend – Phase 2.1

نسخة تطويرية مستقلة للوحة إدارة الأقطار.

تتضمن:
- دخول Admin عبر متغيرات البيئة، بدون كلمة مرور افتراضية داخل الكود.
- الطلبات وحالاتها.
- الشركات، الرصيد، الحد الائتماني والعمولات.
- الإيداع والخصم والاسترجاع.
- إدارة الخدمات/التأشيرات وإظهارها أو إخفاؤها.
- API أولي للخدمات والطلبات.
- قاعدة SQLite للتطوير المحلي فقط.

## مهم قبل النشر
هذه ليست نسخة إنتاج نهائية. قبل استقبال بيانات عملاء حقيقية سنستخدم PostgreSQL وتخزين ملفات خاص وآمن، HTTPS، حماية إضافية للدخول، ونسخ احتياطي. لا ترفع مستمسكات حقيقية إلى GitHub.

## متغيرات التشغيل المطلوبة
SECRET_KEY
ADMIN_USER
ADMIN_PASSWORD
PORT (اختياري)

## التشغيل
python -m pip install -r requirements.txt
python app.py
